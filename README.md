## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Bun`, `Burger`, `Ingredient`, `Database`.

Функция `main()` (сценарий сборки бургера) протестирована двумя способами:
- изолированно: классы `Database` и `Burger` подменяются моками через
  `unittest.mock.patch`, проверяются вызовы методов и их аргументы;
- интеграционно: на реальных объектах — проверяется, что сценарий
  выполняется целиком и печатает чек в stdout.

Дополнительно написаны негативные тесты для класса `Burger`:
поведение при отсутствии булки, при `None` в списке ингредиентов,
а также зафиксировано поведение метода `remove_ingredient(-1)`
(в Python `pop(-1)` удаляет последний элемент, а не бросает ошибку).

Процент покрытия 100% (отчет: `htmlcov/index.html`)

Примечание: строки с точкой входа `if __name__ == "__main__":` в файле
`praktikum/praktikum.py` не выполняются при импорте модуля тестами,
поэтому исключены из замера покрытия через секцию `exclude_lines`
в файле `.coveragerc`. Сам код программы при этом не изменялся.
Вся логика функции `main()` покрыта тестами полностью.

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты, разделенные по классам:
  `test_bun.py`, `test_burger.py`, `test_database.py`,
  `test_ingredient.py`, `test_praktikum.py`

- `tests/conftest.py` - общие фикстуры pytest (моки `Bun`, `Ingredient`,
  готовый `Burger`, мок-база `Database`)
- `tests/helpers.py` - фабрики моков `make_bun` и `make_ingredient`,
  позволяющие создавать моки с произвольными параметрами (используются
  в параметризованных и негативных тестах)
- `.coveragerc` - конфигурация отчета о покрытии (исключение точки входа)
- `pytest.ini` - настройки запуска pytest

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

> `$ pytest --cov=praktikum --cov-report=html`

**Запуск автотестов с отчетом в терминале**

> `$ pytest --cov=praktikum --cov-report=term-missing`

После запуска с `--cov-report=html` отчет открывается в браузере:
`htmlcov/index.html`.
